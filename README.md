# BRAWLZERK 공식 프레스킷

이 폴더의 내부 파일 전체를 GitHub의 공개 저장소 reforbli/press-kit 최상단에 업로드하면 됩니다.

## GitHub Pages 설정

1. 저장소의 Settings에서 Pages로 이동합니다.
2. Source를 Deploy from a branch로 설정합니다.
3. main 브랜치와 /(root) 폴더를 선택한 뒤 저장합니다.
